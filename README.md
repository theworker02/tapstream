# tapstream

Tap HTML/Markdown stream fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/tapstream/

## Install / run

```bash
git clone https://github.com/theworker02/tapstream.git
cd tapstream
node src/cli.js
node --test
```
